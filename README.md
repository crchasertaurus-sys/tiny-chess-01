A chess engine in at most 4 KB of Python: 0x88 board, negamax alpha-beta search with MVV-LVA capture ordering and formula piece-square evaluation, deterministic under a fixed node budget. It plays the make.fun gauntlet through the trial env, sending its moves in UCI.

## Run it

```sh
python3 main.py
```
